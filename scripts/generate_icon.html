App Icon Generator

How to Use

  1. Click each download button to save all 3 sizes
  2. In Xcode, open Images.xcassets → AppIcon
  3. Drag icon-1024.png to the 1024x1024 slot
  4. Drag icon-180.png to the 60pt @3x slot
  5. Drag icon-120.png to the 60pt @2x slot
  6. Archive and upload again!
